# TeslaPrimeCapital — Phase 3 Production Implementation Plan (`Phase 2`)

---

## 1. Phase 3 Engineering Execution Blueprint

Upon receiving explicit user authorization to begin **Phase 3 (Production Implementation)**, the engineering team will execute the project strictly sequentially across **13 iterative implementation milestones**. Each milestone requires thorough self-review, compilation verification, and test execution before presentation.

### 1.1 Comprehensive Milestone Execution Schedule
1. **Milestone 1 — Core Infrastructure & Shared Utilities Setup:** Initialize Next.js 14+ App Router, TypeScript (`strict: true`), Tailwind CSS (`globals.css`), Coolify multi-stage Docker configuration (`deploy/docker/*`), shared JSON envelope definitions (`contracts/api.envelope.ts`), and `Decimal` fixed-point helper utilities (`utils/decimal.util.ts`).
2. **Milestone 2 — Database Schema Definition & Connection Management:** Construct the exact `schema.prisma` relational model enforcing `NUMERIC(20,8)` data types across all financial entities, generate initial Prisma migrations (`prisma migrate dev`), configure `PgBouncer` connection pooling (`lib/prisma.ts`), and create automated database seeders (`prisma/seed.ts`).
3. **Milestone 3 — Authentication & Identity Security Engine:** Implement Argon2id password hashing (`services/auth.service.ts`), cryptographic OTP verification (`validators/auth.validator.ts`), our approved **Hybrid Rotating Session Model** (15m JWT + 7d rotating `httpOnly` Redis cookies), and Time-based One-Time Password (`TOTP`) MFA verification.
4. **Milestone 4 — User Terminal Dashboard & Multi-Currency Wallet UI/API:** Build the responsive user dashboard (`DashboardLayout`), currency tab selector (`USD`, `EUR`, `BTC`), double-entry immutable ledger accounting (`services/wallet.service.ts`), and `Redlock` distributed mutex enforcement (`lib/redis.ts`).
5. **Milestone 5 — Multi-Gateway Deposit & Treasury Withdrawal Pipelines:** Integrate deterministic deposit address generation, incoming payment gateway webhook verification (`workers/webhook.worker.ts`), and implement the approved **100% Mandatory Admin Review** rule for every withdrawal request (`status = 'PENDING_REVIEW'`).
6. **Milestone 6 — Structured Investment Marketplace & Lump-Sum Engine:** Build interactive plan browsing cards (`PlanCard`), capital allocation locking, and the asynchronous `BullMQ` daily worker (`workers/accrual.worker.ts`) implementing our approved **Lump Sum at Plan Maturity** policy.
7. **Milestone 7 — Multi-Tier Affiliate & Referral Commission Engine:** Build unique referral URL generators (`?ref=CODE`), parent-child tree traversal (`UserReferral`), and implement the approved **Active Investment Allocation Trigger** (`5% / 2% / 1%` commission crediting).
8. **Milestone 8 — Comprehensive KYC & Compliance Verification Center:** Build multi-step identity upload wizards (`KYCEditor`), Cloudinary secure signed upload helpers (`services/kyc.service.ts`), and enforce the approved **Tier 0 Starter ($1,000 Limit without KYC)** verification gate.
9. **Milestone 9 — Real-Time Multi-Channel Notification Engine:** Build Redis atomic unread badge counters (`unread_count:user_{ID}`), Server-Sent Events (`SSE`) streaming endpoint (`/api/v1/notifications/stream`), and Resend React Email templates (`services/templates/*`).
10. **Milestone 10 — Enterprise Administrative Governance Portal (`/admin`):** Build hierarchical RBAC dashboards (`AdminLayout`) strictly segregated for `SUPER_ADMIN` (user management), `COMPLIANCE_OFFICER` (5-minute signed KYC review queue), and `FINANCE_MANAGER` (100% withdrawal approval sign-off).
11. **Milestone 11 — Advanced Analytics & Exportable Financial Reporting:** Build high-performance interactive growth charts (`Recharts`), daily platform yield aggregation tables, and exportable CSV/PDF user tax statement generators (`services/reporting.service.ts`).
12. **Milestone 12 — Enterprise Security Hardening & Performance Optimization:** Implement Redis leaky-bucket rate limiting (`middlewares/rate-limit.middleware.ts`), security headers (`CSP, HSTS`), IP geographic velocity checks, append-only `AuditLog` tracking, composite index profiling (`< 10ms` single-lookup target), and Next.js bundle optimization (`< 150 KB` initial chunk).
13. **Milestone 13 — Final QA Suite, Concurrency Stress Testing & Go-Live Preparation:** Execute the complete Vitest/Supertest/Playwright test pyramid, perform race condition stress testing (`50 concurrent requests`), verify container health endpoints (`/api/v1/healthz`), and prepare final Coolify production cutover.
