# TeslaPrimeCapital — Enterprise System Architecture & Technical Design Specification (`Phase 2`)

## 1. System Topology & Containerized Architecture

**TeslaPrimeCapital** is engineered as a cloud-agnostic, containerized enterprise web platform deployed inside a **Coolify / Docker Compose** cluster. The system adheres to strict modular separation between edge traffic routing, server-rendered presentation, RESTful business services, asynchronous background task queues, and persistent ACID/in-memory data stores.

### 1.1 High-Level Technical Architecture Topology
```
                  [ Global Client Tier ]
          (Web Desktop, Mobile Browser, API Clients)
                             │
                             ▼
              [ Cloudflare / Edge CDN Tier ]
     (DNS, DDoS Mitigation, WAF, Static Asset Pre-caching)
                             │
                             ▼
         [ Coolify Reverse Proxy Tier (Traefik/Nginx) ]
      (SSL/TLS Termination, Rate Limiting, Host Routing)
                             │
             ┌───────────────┴───────────────┐
             ▼                               ▼
 [ Next.js Frontend Container ]   [ Node.js API Gateway & Services ]
 (SSR, Static Pages, Client UI)   (REST API, Auth, RBAC, Validation)
             │                               │
             └───────────────┬───────────────┘
                             │
            ┌────────────────┼────────────────┐
            ▼                ▼                ▼
     [ PostgreSQL ]    [ Redis Cluster ]  [ Background Workers ]
   (ACID Financial    (Distributed Cache,  (BullMQ Cron Engine,
```

## 3. Directory Responsibility & Anti-Pattern Prohibition

To preserve enterprise maintainability throughout Phase 3 implementation, the following architectural boundaries are strictly enforced:
1. **No Business Logic in Controllers:** Controllers (`src/server/controllers/`) are strictly responsible for extracting HTTP request parameters, calling `validate.middleware.ts`, invoking the appropriate service (`src/server/services/`), and wrapping the returned data in `IApiResponse<T>`.
2. **No Direct Database Calls in Services:** Domain services (`src/server/services/`) must never write raw SQL or invoke `prisma.*` directly. All database interaction must flow through dedicated repositories (`src/server/repositories/`).
3. **No Mathematical Operations with Raw JavaScript Numbers:** Any function inside `src/server/` or `src/utils/` that performs financial calculation (yield interest, conversion spread, balance debits) must strictly use `Decimal` / `decimal.util.ts`. Using `+`, `-`, `*`, or `/` on raw JavaScript floating-point numbers (`number`) is classified as a critical security defect.
